# MINIMA — WhatsApp через GREEN-API

React-клиент для личного WhatsApp-аккаунта. Проект адаптирован под WhatsApp по запросу пользователя.

## Запуск

Требуется Node.js 22.12+.

```bash
npm install
npm run dev
```

Приложение: http://localhost:5173. Сервер: http://localhost:3001.

## Подключение

1. В https://console.green-api.com/ создайте бесплатный инстанс WhatsApp Developer или используйте существующий.
2. Введите apiUrl, idInstance и apiTokenInstance в форме приложения. Используйте точный API URL из кабинета; пример: https://7201.api.green-api.com.
3. Если инстанс ещё не авторизован, приложение покажет обновляемый QR-код. На телефоне: WhatsApp → Настройки (или меню ⋮) → Связанные устройства → Привязать устройство.
4. После сканирования QR-кода приложение автоматически подключится и загрузит список чатов.
5. Новый чат можно открыть по международному номеру телефона или chatId. Поддерживаются личные ID @c.us, ID @lid и группы @g.us. Для проверки номера используется checkWhatsapp.

Приложение включает уведомления о входящих и исходящих сообщениях. Если у инстанса уже задан внешний Webhook URL, очистите его в кабинете, чтобы получать уведомления через HTTP API. Изменения настроек GREEN-API могут применяться с задержкой.

Токен хранится только в оперативной памяти Node-сервера до 12 часов. После перезапуска сервера нужно повторить подключение. В localStorage сохраняется список контактов отдельно для каждого инстанса, без токена. Демо-режим не отправляет реальные сообщения.

Бесплатный Developer имеет ограничения по количеству чатов. Они задаются GREEN-API и не снимаются приложением.

## Проверка

```bash
npm test
npm run build
npm start
```

Производственный сервер: http://localhost:3001. Поддерживаются текстовые сообщения, история, статусы и получение новых сообщений через receiveNotification с подтверждением deleteNotification.

Документация: https://green-api.com/docs/.
